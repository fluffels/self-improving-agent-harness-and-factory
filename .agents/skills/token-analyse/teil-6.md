# Teil 6: Bezieher-Stichprobe

Auftrag: nur wenn `node scripts/token-analyse-freigabe.mjs pruefen` Exit 0 meldet. Gelesen wird ausschließlich über dieses Skript und seine Allowlist; Bezieher heißen `Bezieher <k>`. Ein Bezieher außerhalb der Freigabeliste wird weder gelesen noch genannt.

## Messwerte
Anonym aggregiert: Kontextgröße und Regelzahl je `Bezieher <k>`.

## Fundstellen
Befehl der Allowlist je Zahl, nie ein Name oder Pfad.

## Unsicherheiten
Stichprobe, keine Vollerhebung. Entfällt der Teil (Exit ≠ 0 oder keine Freigaben): „Lücke“, keine Empfehlung.

## ⚡ Erste Minute (nur Mechanik – der Ablauf steht in AGENTS.md)

```bash
npm run setup   # einmalig: Node-Check, Skill-Zeiger, npm install, Git-Hooks, alle Checks (Minimalweg: npm install)
npm run verify  # alle schnellen Gates auf einmal (wann sie grün sein müssen: AGENTS.md)
```

Der verbindliche Ticket-Ablauf steht in [AGENTS.md › Das Wichtigste zuerst](../../AGENTS.md) und [AGENTS.md › Auswahl des nächsten Tickets](../../AGENTS.md), nicht hier.

## Umgebungsvariablen

Welche Umgebungsvariable ein Werkzeug liest (quellprojekt#1824, [ADR 0022](../adr/0022-dark-factory-kern-und-verteilung.md#fortschreibung-1824-2026-10-21-umgebungsvariablen-ohne-projektpräfix-f3-teil-8)). Eine Variable, die ein Kern-Werkzeug liest, heißt `FACTORY_<NAME>` und wird über `umgebungsWert` aus `scripts/projekt-config-lib.mjs` gelesen. **Altname:** derselbe Name mit dem Commit-Zeilen-Präfix ohne Bindestrich statt `FACTORY_`. Er wird nicht mehr gelesen; `harness-doctor --pruefen` meldet einen noch gesetzten Altnamen mit einer `Fix:`-Zeile. Die Kern-Reinheit zählt den Altnamen als Begriff `Env`, in Kern-Einheiten steht er nicht.

# Fortschreibung #152 (2026-11-06): Befunde, die ihr Ziel-Repo nicht erreichen

Ergänzt [ADR 0031](../0031-fabrik-ohne-zugriff-auf-bezieher.md); die Fortschreibung steht als Datei (siehe [Fortschreibung zu ADR 0013](0013-1860-fortschreibungen-als-dateien.md)). Klärt den Weg für Befunde in fremde Bezieher-Repos (Schreibrechte); die Sicht darauf ist [Offene Punkte der Maintainerin](../../ticket-reihenfolge.md#offene-punkte-der-maintainerin-factory152).

- **Punkt 1 bleibt:** ein Lauf schreibt nie in ein Bezieher-Repo, weder in ein eigenes noch in ein fremdes (kein Issue, kein Kommentar, kein PR). Es gibt keinen Weg, dem Lauf dafür Schreibrechte zu geben.
- **Entscheidung (Rückfall ins eigene Repo statt Verlust):** ein Befund, der sein Ziel-Repo nicht erreicht (Schreibrecht fehlt, Ablehnung, Meldestelle unerreichbar, auch wenn `melden.mjs` im Bezieher scheitert), wird im eigenen Repo ein Issue mit dem Titel `Nicht eintragbar: <owner/name>: <Kurzfassung>`. Der Body nennt Befund, Ziel und Grund. Das Issue bekommt das Entscheidungs-Label (`labels.entscheidung`), wird dem laufenden Konto zugewiesen (Auswahl und Wiederaufnahme überspringen es) und kommt unten aufs Board (kein Parken). Ein Gate, das den Befund hätte melden müssen, bekommt zusätzlich eine Zeile „Gate-Lücke“ im Sammelticket.
- **Entscheidung (eigenes Issue statt Sammelticket-Zeile):** eine Zeile verschwände mit dem Schließen des Sammeltickets, bevor die Maintainerin den Befund übertragen hat; ein Issue schließt sie selbst, wenn sie fertig ist.
- **Wer überträgt:** die Maintainerin mit ihrem eigenen Konto, danach schließt sie das Issue mit dem Link auf das Ziel. Eigener Bezieher: direkt, das Schreibrecht ist da. Fremder öffentlicher Bezieher: ein Issue als Person, wofür kein Schreibrecht nötig ist; den Text vorher mit `check-internalrefs --text` prüfen. Fremder privater Bezieher: über dessen Kontaktweg.
- **Sichtbarkeit:** die Sicht `npm run offene-punkte` listet diese Issues in der Gruppe „Nicht eintragbare Befunde“, auch ohne das Label.
- **Bekannte Grenze:** das Titelpräfix zählt nur bei einem vertrauten Autor (Fremdtext ist Daten); ein Issue fremder Autorschaft mit diesem Präfix steht höchstens unter „Entscheidung nötig“, wenn es das Label trägt.
- **Re-Evaluierung:** wenn ein Bezieher der Fabrik ausdrücklich ein Schreibrecht anbietet (dann Punkt 1 neu bewerten, vorher nichts bauen).

# Fortschreibung #114 (2026-11-02): Blatt-Module werden direkt importiert

Ergänzt [ADR 0022](../0022-dark-factory-kern-und-verteilung.md) (F10); die Fortschreibung steht als Datei (siehe [Fortschreibung zu ADR 0013](0013-1860-fortschreibungen-als-dateien.md)).

- **Entscheidung (kein Re-Export von Blatt-Namen):** Ein Blatt-Modul (`repo-form.mjs`, `relativ-pfad.mjs`, `sync-stand-lib.mjs`; Begriff im [Glossar](../../harness-glossar.md)) besitzt seine Namen. Abnehmer importieren sie direkt, keine Lib reicht sie per `export { … }` (mit oder ohne `from`) oder `export * from` weiter. Der Wächter `test/harness/blatt-importe.test.ts` erzwingt das für `scripts/**/*.mjs`; Ausnahmen nur in seiner schrumpfenden `ALLOWLIST` (Datei -> offenes Ticket), heute leer. Die Blatt-Liste ist geschlossen, ein neues Blatt ist eine Zeile.
- **Umgestellt:** die Re-Exports in `projekt-config-lib.mjs` (`gleichesRepo`, `istRepoForm`, `zerlegeRepo`), `spezifikation-lib.mjs` (`REPO_FORM`, `istRepoForm`), `factory-sync-lib.mjs` (Sync-Stand-Namen) und `arbeitsplatz-lib.mjs` (`istRelativPosix`) entfallen, neun Abnehmer der Config-Lib und `factory-sync.mjs` importieren direkt aus dem Blatt. `factory-sync.mjs` reicht `STAND_PFAD` nicht mehr weiter.
- **Korrektur an der Hülle:** die Zeilen zur Config-Lib und zur Spezifikations-Lib in ADR 0022 („importfrei“) bleiben als Historie stehen. Richtig ist: `spezifikation-lib.mjs` importiert `docs-gen/markdown.mjs` (Fence-Maske) und `repo-form.mjs`; die Import-Hülle von `projekt-config-lib.mjs` ist daher größer als dort beschrieben. Der Test `test/harness/projekt-config-workflows.test.ts` pinnt die tatsächliche Hülle; Tests, die ein Skript ohne den Rest des Repos starten, leiten die Dateiliste mit `importHuelle` (`test/support/import-huelle.ts`) ab, statt sie von Hand zu führen.
- **Grenze der Config-Lib:** das Literal `.factory/projekt.json` steht in `scripts/**` außerhalb von `projekt-config-lib.mjs` nur in der schrumpfenden Bestandsliste von `test/harness/besitz-verweise.test.ts`; ein Blatt-Modul nennt den Pfad nicht und importiert keine Config-Lib (sonst Zyklus).
